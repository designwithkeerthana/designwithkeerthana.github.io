# Keerthana · Portfolio

Interior designer moving into construction project management.
Live site: https://designwithkeerthana.github.io

## Editing the text

All the words on the site live in **`content.js`**.

1. Open `content.js` on GitHub and click the pencil icon (Edit).
2. Change the words between the quote marks. Keep the quotes, commas and brackets.
3. Click **Commit changes**. The site updates in a minute or two.

## Files

| File | What it is |
| --- | --- |
| `content.js` | Your name, contact details, education, certifications, skills and project list |
| `index.html` | The layout, styles and page logic |
| `assets/portrait.webp` | Your self-portrait |

To replace the portrait, upload a new image named `portrait.webp` into `assets/`.
